# frontend-design

A Claude Code plugin that helps produce distinctive, production-quality
frontend interfaces — instead of the generic, template-looking output models
tend to default to.

## What's inside

- **`skills/frontend-design/SKILL.md`** — the skill. It triggers whenever the
  visual result of web UI work matters: landing pages, marketing sites,
  dashboards, app screens, components, and design systems. It walks through
  committing to a design direction, the craft fundamentals (typography, color,
  space, depth), motion, responsiveness, accessibility, implementation, and a
  final review pass.

## Using it

Install the plugin, and the skill activates automatically when you ask Claude
to build or restyle a frontend — no need to invoke it by name. You can also
read `skills/frontend-design/SKILL.md` directly as a design checklist.
